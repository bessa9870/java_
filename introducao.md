# PROGRAMAÇÃO ORIENTADA A OBJETOS

## Classes:

Pegando de uma perspectiva de alguém que veio do C puro: Uma classe é uma struct bufada que declara as variáveis e também contêm os métodos (funções) que iram trabalhar com essas variáveis. Na programação orientada a objetos dá pra definir uma classe facilmente como: **Construção lógica que define um objeto**.
*(Naturalmente, uma classe não ocupa espaço na memória tal qual uma struct.)*

## Objeto:

O objeto é tão simples quanto, em C, ele seria a variável declarada na main que é do tipo struct. Na programação orientada a objetos a definição seria: **A instância física da classe**, essa instância é uma variável que pode acessar as variáveis e métodos dentro da classe.
